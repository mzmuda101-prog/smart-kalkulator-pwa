# Dymki w krokach — plan wdrożenia

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dymek (kolorowy fragment `⟦…⟧` + `formula: { id, here? }`) w każdym typie zadania z tabeli projektu,
linijka „W tym zadaniu:” z liczbami z zadania, przycisk „W podręczniku ›” przy każdym dymku i Esc zamykający dymek.

**Architecture:** Silniki (`js/math-steps.js`, `js/math-calculus.js`) dokładają do kroków `⟦…⟧` i `formula: { id, here }`.
Hasła dochodzą w `js/step-formulas.js` (format podręcznika). Dymek w `app.js` (`_openStepsPop`) rysuje `here`
przez `MATM0_TEX.stepToLatex`, jak kroki.

**Tech Stack:** czysty JS, MathLive, testy Node + Playwright (Chromium + jeden WebKit), bramka SymPy.

**Spec:** `docs/superpowers/specs/2026-11-23-dymki-design.md`

## Global Constraints
- Kolor `⟦…⟧` tylko na rachunku, w którym reguła hasła działa; litery w `here` = litery z `tex` hasła; `tex` haseł bez zmian.
- `here` w zapisie kroku (jak `math`), np. `a = 1, b = −5, c = 6` (minus `−`, nie `-`); brak `here`, gdy szukana w kroku jest literą wzoru.
- Zdanie „dlaczego” nie powtarza dymku (`test/step-why.js`); bramki `test/expr-to-latex.js`, `test/math-steps.js`, `npm run check:steps` zielone.
- Nowe hasła: `try` przez `MATM0_STEPS.run`, `expect` sprawdzony, równości przez SymPy, czytanie „słabym uczniem”.
- Bez emoji, `:hover` w `@media (hover: hover)`, kolory z tokenów, cel ≥ 44 px.
- Commit: `typ(kalkulator): tytuł po polsku (vX.YY.ZZ)` + „- …”, **bez** `Co-Authored-By`.

## Review Focus
1. `here` z ujemnymi i ułamkowymi współczynnikami (`rozwiąż -x^2 + 7x - 6 = 0`, `wierzchołek 2x^2 + 3x - 2`): znaki i nawiasy zgodne z krokiem → Task 1.
2. Fragment `⟦…⟧` w kroku z kilkoma liniami (`\n`, np. dwa przypadki wartości bezwzględnej): rysunek bez zapisu z klawiatury → Task 3–5 (bramka `expr-to-latex`).
3. Dymek otwarty, potem Esc, potem Tab: fokus wraca na fragment, nie ucieka z szuflady → Task 2.
4. Krok z dwoma dymkami w jednym zadaniu (trygonometria: tablica + okresowość) — stuknięcie drugiego zamyka pierwszy → Task 4.
5. Sposoby (przełącznik `explain.methods`, układy): dymek w obu sposobach, każdy z własnym hasłem → Task 3.
